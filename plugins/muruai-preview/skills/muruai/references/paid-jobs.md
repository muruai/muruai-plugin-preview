# 크레딧이 드는 작업

## 공통 순서

1. 만들기 tool(미리보기만, 크레딧 0) → 할 일·크레딧·승인 번호(10분 유효)
2. 선생님에게 할 일과 크레딧을 그대로 보여 주고 확인받기
3. `approve(approvalId, credits)` → 작업 시작. `credits`가 미리보기와 다르면 시작하지 않는다
4. `get_job`으로 진행 확인 → 끝나면 편집 링크(필요하면 `export_pdf`)

- 승인 번호는 만든 연결에서만 쓸 수 있고 10분이 지나면 만료된다. 만료되면 만들기 tool로 미리보기를 다시 받는다.
- 크레딧이 부족하면 미리보기에서 필요한·남은 크레딧과 함께 거절된다. 그대로 선생님에게 알린다.
- 선생님 확인 없이 `approve`를 부르지 않는다. AI 도구의 실행 확인창은 선생님이 직접 확인하는 마지막 장치다.

## 이야기책 (`make_storybook`, 쪽당 10크레딧)

- 받는 값: 문서, 주제, 쪽수(4·8·12), 아이 나이(1~19), 아이 이름·학습 목표(선택), 그림체·배치(선택, 기본 수채화풍 동화·상하 분할).
- 아이 나이를 모르면 묻는다. 그림체·배치는 선생님이 말하지 않았으면 기본값을 쓰고 미리보기에서 알린다.
- 이야기책 쪽은 고른 자료 끝에 더해진다. 새 자료에 만들려면 `documentId` 대신 `newDocumentTitle`(새 자료 이름)을 보낸다. 새 자료는 승인할 때 만들어지므로 `create_document`를 먼저 부르지 않는다(승인하지 않으면 빈 자료가 남는다).
- 4쪽 기준 몇 분 걸린다. `get_job`을 여러 번 부르게 되니 진행 중임을 짧게 알린다.

## 그림 고치기와 다시 그리기 고르기

| 선생님 요청 | 쓸 tool |
|---|---|
| 지금 그림에서 일부만 바꾸기(인물·물건·색·표정, "나머지는 그대로") | `edit_image` |
| 이야기에 맞게 장면을 새로 그리기, 같은 장면을 다른 그림으로 | `redraw_image` |

- "남자아이를 여자아이로", "가방 색을 빨강으로"처럼 지금 그림을 기준으로 바꾸는 요청은 `edit_image`다. `redraw_image`로 하면 장면이 새로 짜여 배경·구도·인물 수가 바뀔 수 있다.

## 그림 고치기 (`edit_image`, 10크레딧)

- 자료 속 그림 하나를 지금 그림을 원본으로 고친다. 웹 편집 화면의 AI 편집(그림 전체)과 같다.
- 받는 값: 문서, 그림 요소 ID(`get_document`에서 확인, 지어내지 않는다), 바꿀 점.
- 바꿀 점은 무엇을 어떻게 바꾸고 무엇을 그대로 둘지 구체적으로 쓴다. 예: "파란 옷 남자아이를 같은 옷의 여자아이로, 배경·표정은 그대로".
- 이야기책·감정 장면·학습지 안 그림 등 그림이 든 요소면 된다. 무루아이에 저장된 그림만 된다.
- 감정 추론·이야기책처럼 같은 인물이 여러 쪽에 나오면 고친 쪽만 바뀐다. 다른 쪽도 같게 하려면 쪽마다 고친다.
- AI+ 학습지의 문항을 바꾸려면 `plan_worksheet`의 만든 학습지 고치기를 쓴다. 글상자 방식 쪽에서 글만 바뀌면 크레딧 없이 바로 바뀐다.
- 그림 위치·크기는 그대로이고 그림만 바뀐다. 고치기 전 그림은 버전으로 남는다.

## 그림 다시 그리기 (`redraw_image`, 10크레딧)

- AI 이야기책 쪽이나 감정 장면 쪽의 그림 한 장만 된다. 다른 쪽이면 tool이 이유를 알려 준다.
- 그 쪽의 이야기 글로 장면을 다시 계획해 새로 그린다. 지금 그림을 원본으로 쓰지 않고, 주인공 모습(성별 등)은 자료 설정에 묶여 바뀌지 않는다.
- `instruction`에 고칠 점(예: 배경을 놀이터로)을 넣으면 새 장면 계획에 참고로 들어간다. 없으면 같은 이야기로 새로 그린다.
- 그림 위치·크기는 그대로이고 그림만 바뀐다. 바뀌기 전 모습은 버전으로 남는다.
